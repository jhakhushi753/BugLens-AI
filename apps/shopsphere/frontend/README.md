# ShopSphere Storefront

React and Vite storefront for the ShopSphere demo. It runs at http://localhost:3000 and uses the API at http://localhost:8000.

## Run locally

```bash
npm install
npm run dev
```

The store includes a product catalog, category filters, search, price sorting, favorites, a server-backed cart, and simulated checkout. The price ascending option intentionally sorts in descending order so the frontend defect can be reproduced and sent to BugLens.

## Build

```bash
npm run build
```
